# Job Garages
#### Job garages FiveM script for QBOX and ESX frameworks
##### UI is inspired by [jg_dealerships](https://jgscripts.com/scripts/dealerships)
<img width="1920" height="1080" alt="jobgar" src="https://github.com/user-attachments/assets/0f56efb7-d28a-45ee-b254-605f9fafeb36" />

### Features
- Multiple vehicle spawn locations
- Vehicle preview
- Color picker for vehicle colors
- Multiple vehicle preview locations
- Job-grade locked vehicles
- Multiple vehicle return locations

### Requirements
- QBOX or ESX framework
- [ox_lib](https://github.com/CommunityOx/ox_lib)
- [ox_target](https://github.com/CommunityOx/ox_target) or [sleepless_interact](https://github.com/Sleepless-Development/sleepless_interact)
